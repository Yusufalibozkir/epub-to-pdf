Deluxe EPUB to PDF - CLI Options Quick Reference
================================================

Typical sample command
----------------------
.\.venv\Scripts\python.exe deluxe_epub_to_pdf.py "book.epub" --config "my_style.yaml" --out "sample.pdf" --sample-pages 50 --debug-html

Typical DeepSeek command (text QA + rule suggestions)
-----------------------------------------------------
$env:DEEPSEEK_API_KEY="your-key"
.\.venv\Scripts\python.exe deluxe_epub_to_pdf.py "book.epub" --config "my_style.yaml" --ai-provider deepseek --use-openai --out "sample.pdf" --sample-pages 50 --max-auto-fix-passes 2 --debug-html

Typical OpenAI visual QA command
--------------------------------
$env:OPENAI_API_KEY="your-key"
.\.venv\Scripts\python.exe deluxe_epub_to_pdf.py "book.epub" --config "my_style.yaml" --ai-provider openai --openai-qa --out "sample.pdf" --sample-pages 50 --debug-html

Package entry point (same as wrapper)
--------------------------------------
.\.venv\Scripts\python.exe -m pipeline "book.epub" --config "my_style.yaml" --out "sample.pdf" --sample-pages 50


Input and output
----------------
epub
  Input EPUB path. Required unless using --write-default-config.

--out
  Output PDF filename/path. Bare filenames go under --output-dir. Default: print_ready.pdf.

--output-dir
  Folder for PDFs when --out is a bare filename. Default: output.

--artifacts-dir
  Folder for QA reports, rendered QA pages, debug builds, and cache. Default: artifacts.

--title
  Optional clean title override. Omit normally; EPUB metadata is used automatically.

--config
  YAML or JSON config file. Example: --config "my_style.yaml".

--write-default-config
  Write a complete editable default config and exit.


Sampling and build intent
-------------------------
--sample-pages
  Build only the first N PDF pages for review. Recommended before full builds.

--full-without-sample
  Intentionally build the full book without sample-first warning.

--no-sample-requirement
  Disable the sample-first warning (config key: no_sample_requirement).


Core typography
---------------
--body-size
  Body font size in pt. Config key: body_size_pt.

--line-height
  Body line-height multiplier. Config key: line_height.

--font-stack / --font-family
  CSS font-family stack. Config key: font_stack.

--font-dir
  Folder containing local font files. Config key: font_dir.

--embedded-font-family
  CSS @font-face family name for local embedded font files.

--embedded-font-regular
  Regular/upright font filename inside --font-dir.

--embedded-font-italic
  Italic font filename inside --font-dir.

--embedded-font-weight
  CSS font-weight or range for embedded font files, e.g. "400" or "400 800".

--no-embed-font-files
  Disable local @font-face embedding and rely on installed system fonts.


Page margins
------------
--margin-top
  Main body page top margin in mm. Config key: margin_top_mm.

--margin-side
  Equal left/right margin in mm. Config key: margin_side_mm.

--margin-bottom
  Bottom margin in mm. Config key: margin_bottom_mm.


Running heads and folios
------------------------
--runner-font
  Running-head font size in pt. Config key: runner_font_pt.

--folio-font
  Page-number/folio font size in pt. Config key: folio_font_pt.

--runner-rule-gap
  Gap between running-head text and CSS rule in mm. Config key: runner_rule_gap_mm.

--runner-body-clearance
  Extra top body margin after margin_top_mm. Config key: runner_body_clearance_mm.

--runner-rule-y
  Full-width vector runner rule position from top trim in mm. Config key: runner_rule_y_mm.

--runner-title-top
  Running-head title offset from top trim in mm. Config key: runner_title_top_mm.

--runner-layout
  Running-head layout. Choices: right_title_full_rule, centered_single_rule, dual_full_rule, alternating.

--runner-rule-style
  Runner rule rendering style. Choices: full_width, single, split, none.
  Config key: runner_rule_style.

--runner-collection-transform
  CSS text-transform for collection title runner, e.g. none or uppercase.

--runner-work-transform
  CSS text-transform for current-work runner, e.g. uppercase or none.


Paragraphs, headings, verse
---------------------------
--paragraph-indent
  Paragraph first-line indent in em. Config key: paragraph_indent_em.

--subdivision-margin-top
  Chapter/subdivision heading top margin in mm. Config key: subdivision_margin_top_mm.

--subdivision-margin-bottom
  Chapter/subdivision heading bottom margin in mm. Config key: subdivision_margin_bottom_mm.

--verse-line-height
  Verse line-height multiplier. Config key: verse_line_height.

--verse-max-width
  Verse block max width in mm. Config key: verse_max_width_mm.


Typography refinements (CLI)
----------------------------
--no-drop-caps
  Disable decorative drop caps at chapter starts (config key: drop_caps).

--no-small-caps
  Disable automatic small-caps normalization for abbreviations (config key: small_caps).

--ligature-setting
  CSS font-variant-ligatures setting. Choices: common, none, all, discretionary.

--footnote-handling
  How to handle inline footnote bodies. Choices: auto, endnotes-only, disabled.


Config-only collected-works apparatus keys
------------------------------------------
work_description_font_delta_pt
  Size adjustment for editorial descriptions after major work titles. Default: -1.0.

work_description_bottom_margin_mm
  Bottom margin after editorial descriptions before the author's text. Default: 7.0.

Notes
  Subtitles (e.g. "A PETERSBURG POEM") stay roman.
  Editorial descriptions (e.g. "The novella...") are styled smaller italic.
  Local QA inspects rendered PDF fonts/sizes for detected work descriptions.

part_heading_font_pt / part_heading_margin_bottom_mm
  Compact in-work part labels such as "PART I".

chapter_section_font_pt / chapter_section_margin_top_mm / chapter_section_margin_bottom_mm
  Compact section labels such as "INTRODUCTION" below "CHAPTER I".


Images and cleanup
------------------
--keep-all-images
  Keep all EPUB images. Overrides image_policy setting.

--remove-all-images
  Remove all EPUB images. Overrides image_policy setting.

--no-smart-punctuation
  Disable conservative punctuation cleanup (config key: smart_punctuation).


Caching
-------
--no-cache
  Disable content-addressed caching of intermediate pipeline results.
  Use when iterating on rule packs or plugin changes.


QA, debug, and optimization
---------------------------
--no-optimize
  Skip pikepdf PDF optimization.

--no-qa-render
  Do not render PNG QA page images.

--debug-html
  Keep generated HTML/CSS build folder in artifacts/<run>/build/.

--strict
  Exit non-zero when delivery-blocking QA warnings remain.

--max-auto-fix-passes
  Maximum re-renders after local/AI safe CSS/config fixes. Default: 1.
  Each pass re-runs QA; fixable issues (header clearance, TOC spacing, etc.)
  are adjusted automatically.


AI providers
------------
--ai-provider
  Provider for text/structure AI tasks. Choices: openai, deepseek, none. Default: openai.

--use-openai
  Use the selected --ai-provider for whole-book structure planning.

--openai-model
  OpenAI model for structure/image/visual QA. Default: gpt-5.4-mini.

--deepseek-model
  DeepSeek model for structure/text QA. Default: deepseek-chat.

--openai-image-check
  Use the selected --ai-provider to classify each image/caption block.
  Can increase API cost on image-heavy EPUBs.

--openai-qa
  Send rendered QA page images to OpenAI vision for visual review.

--openai-qa-pages
  Maximum rendered pages sent to OpenAI visual QA. Default: 10.

--ai-qa-pages
  Maximum sequential PDF pages scanned for AI text QA (plus work-opening pages). Default: 50.

--no-text-qa
  Disable provider text QA (e.g. DeepSeek post-local-QA review).


Environment variables
---------------------
OPENAI_API_KEY
  Required for OpenAI structure/image/visual QA.

DEEPSEEK_API_KEY
  Required for --ai-provider deepseek.
